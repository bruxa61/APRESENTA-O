## 📌 Sobre o Projeto
O projeto simula a experiência de uma loja real, ideal para estudos e demonstração de habilidades em desenvolvimento web.

## ⚙️ Funcionalidades

- 🛍️ Catálogo de produtos com imagens, preços e descrições  
- 🛒 Carrinho de compras com cálculo automático
